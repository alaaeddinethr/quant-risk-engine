Context

Professional-grade risk analytics

Value-at-Risk is the industry standard for quantifying market risk. This project implements a complete VaR/CVaR pipeline across four computational methods — from the simplest historical simulation to full Cholesky-correlated Monte Carlo — giving both breadth of coverage and depth of understanding.

Beyond risk measurement, the engine includes Markowitz portfolio optimization, a full efficient frontier computation, and historical stress testing against the four major market crises of the past 25 years.

"VaR is the maximum loss expected over a target horizon within a given confidence interval. It is the benchmark for financial risk management." — Jorion, P. (2006). Value at Risk: The New Benchmark for Managing Financial Risk. McGraw-Hill.

Methodology

Four approaches to measuring risk

Each method makes different assumptions about the return distribution. Using all four — and comparing their outputs — gives a robust picture of downside risk. When methods diverge, it signals non-normal return characteristics: fat tails, skewness, or regime changes.

VaRα = inf{l : P(L > l) ≤ 1−α}
CVaRα = E[L | L ≥ VaRα]
// CVaR = average loss in the worst (1-α) scenarios

MC: rt = μ + L·z, z ~ N(0,I)
// L = Cholesky(Σ) — correlation structure
01 —
Historical Simulation
Uses the empirical quantile of the observed P&L distribution. No distributional assumptions.
+ Fully non-parametric + Captures real market regimes − Limited by history length − Can't extrapolate tail events
02 —
Parametric Normal
Assumes N(μ, σ²). Analytically tractable — VaR = μ + zα·σ. CVaR has closed form.
+ Fast and analytical + Easy to decompose by asset − Underestimates fat tails − Real markets: excess kurtosis
03 —
Parametric Student-t
MLE-fitted t(ν, μ, σ). Degrees of freedom ν controls tail heaviness. Typical equities: ν ≈ 3–6.
+ Models fat tails explicitly + ν→∞ converges to Normal − Less interpretable − Symmetric tails assumption
04 —
Monte Carlo (Correlated)
GBM simulation with Cholesky-decomposed covariance. Preserves cross-asset correlation structure.
+ Full correlation structure + Flexible for any payoff − Computationally intensive − Model risk (GBM assumptions)

Clone & install

  alaaeddinethr/quant-risk-engine
cd quant-risk-engine

# Install dependencies
pip install -r requirements.txt

# Run the test suite
pytest tests/ -v

Compute risk report

# Fetch market data
